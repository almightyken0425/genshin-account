# HOYO

[開啟 HOYO](https://ken-genshin-archive.almightyken0425.chatgpt.site)，目前公開，沿用使用者已確認的分享設定。

## 來源與資料

Sites託管庫保存網站來源，web是對應來源副本，source.json記錄實際部署版本。GitHub main的data/account.json保存原神現況，data/zzz/account.json保存獨立的絕區零觀測。正式API在每次讀取時取得main版本，帳號及證據按同一revision驗證，不使用測試資料代替正式帳號。

第35至42版依使用者要求先在Sites審閱尚未推送的觀測，曾使用伺服器唯讀快照。第43版移除快照覆寫與生成工具，網站直接讀取已合併至GitHub main的正式資料。

保留原 GitHub repo 與 Site 網址，產品名稱改為 HOYO。未更改登入權限。全站介面唯讀，原神既有角色、隊伍、培養頁與循環卡片保持原有功能。

## 本機圖片編輯稿

在 `web` 執行 `npm run artwork:edit`，開啟 [圖片編輯器](http://127.0.0.1:4180/genshin/roster)。原神與絕區零各有角色列表與角色詳情總覽。詳情共用正方形圖框，列表共用 3:4 大卡。操作與保存方式見 [編輯器說明](web/tools/artwork_editor/README.md)。

本機編輯稿的正式保存位置是 `web/lib/artwork_edits.json` 與 `web/public/assets/artwork_edits/`。這兩組檔案須一起保留，並在使用者確認後一起帶入 Sites 部署。尚未部署的本機編輯稿不應被舊託管來源覆蓋。source.json 仍只描述上次正式部署。

第43版沿用第127次修訂的88張編輯圖片。原神列表 46 張，絕區零列表 26 張、詳情 16 張。其餘圖片沿用既有構圖。後續本機編輯仍須再次部署才會更新正式網站。

角色詳情以兩遊戲共用的數值元件及有效底色標記。有效屬性依據預設收合，展開可查看用途、條件與來源。條件式屬性不直接亮底，不把培養優先度較低一概當成無效。

此研究只影響原神面板標記。聖遺物有效性仍依遊戲觀測，原始資料、強化次數、有效計數、上限及既有面板均未修改。兩款遊戲的觀測與規則保持獨立。
