# 本機圖片構圖編輯器

四個總覽顯示目前編輯稿的實際圖片，並使用網站共用的人物元件。儲存會更新本機檔案，關閉瀏覽器後仍保留。編輯器不會部署網站。

## 開啟與編輯

在 `site/web` 執行 `npm run artwork:edit`。預設只監聽本機連線。

| 總覽 | 網址 | 圖框 |
| --- | --- | --- |
| 原神角色列表 | http://127.0.0.1:4180/genshin/roster | 3:4 |
| 原神角色詳情 | http://127.0.0.1:4180/genshin/portrait | 1:1 |
| 絕區零角色列表 | http://127.0.0.1:4180/zzz/roster | 3:4 |
| 絕區零角色詳情 | http://127.0.0.1:4180/zzz/portrait | 1:1 |

點選角色進入編輯頁。中間未被遮住的區域會保留，半透明遮罩下的區域會裁掉。拖曳移動原圖，使用縮放按鈕、滑桿、滾輪或雙指手勢調整大小。圖面取得焦點後，方向鍵可以微調位置。Shift 加方向鍵可加大移動幅度。

縮放百分比可直接輸入整數，範圍為 10% 至 2000%。加減按鈕每次調整 4 個百分點，數值欄位旁的上下按鈕及欄位內的上下方向鍵每次調整 1 個百分點。格線使用明暗雙色，方便對齊不同底色的圖片。

儲存構圖會產生透明圖片並返回總覽。取消會捨棄這次尚未儲存的調整。重設位置會回到內建構圖，仍須儲存才會套用。原圖來源選單只提供已核對的 HoYoWiki 素材。旅行者使用已核對的女性原畫區域。

列表輸出為 600×800，詳情輸出為 900×900。兩款遊戲使用相同規則。放大會改變構圖，不會補出原圖沒有的細節。

## 保存與網站預覽

編輯稿由兩組檔案組成，保存或交接時須一起保留。

- `lib/artwork_edits.json` 記錄每位角色的來源、構圖、修訂與校驗值。
- `public/assets/artwork_edits/` 保存儲存後的實際透明 WebP。

每個角色的列表圖與詳情圖分開儲存。不同角色可以分別更新。相同圖片若已在另一個分頁被儲存，舊分頁會顯示修訂衝突，避免覆蓋較新的構圖。

完整網站預覽預設使用 http://127.0.0.1:5173/ 。在另一個終端機從 `site/web` 執行 `GENSHIN_PREVIEW_REPO=../.. npm run dev -- --host 127.0.0.1`。本機網站與四個總覽讀取相同編輯稿，儲存後重新整理即可檢查。

第一次安裝依網站的套件流程取得依賴。若程式不在 HOYO 專案目錄內，可使用 `--account-repo` 指定含有兩款遊戲資料的專案。`--port` 可指定編輯器連接埠，`--preview-url` 可指定網站預覽網址。同一份專案只啟動一個編輯器程序。

## 部署交接

先在四個總覽確認構圖，再依 Sites 流程部署。本機儲存不會改變正式網站或帳號資料。

部署前必須將上述兩組編輯稿檔案帶入 Sites 來源，保留對應原圖、共用元件與素材選擇器。不要用舊的託管來源覆蓋尚未部署的本機編輯稿。建置前的檢查會核對來源、輸出尺寸與校驗值，檢查失敗時先調查檔案是否缺漏。

編輯器是本機工具，不在正式網站暴露寫入介面。`site/source.json` 只記錄已部署的版本，不因本機編輯而更新。
