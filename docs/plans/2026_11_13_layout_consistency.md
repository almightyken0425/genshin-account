邦布作為獨立同伴類型，不冒充角色，不開啟角色詳情。八隊以官方技能條件檢查相容搭配，顯示為建議。帳號沒有邦布觀測，持有、等級、星級與裝備狀態仍未知。

## 有效副詞條

使用者已選擇包含初始詞條，複合值改為目前／最大。目前值維持逐件觀測的有效副詞條初始一次與已命中強化次數加總，最大值改為同稀有度、相同主詞條下的理論有效上限，不再使用全部副詞條的物理分配容量。

先從角色目前裝備的已確認有效標記取得有效屬性集合，再排除與主詞條相同的屬性。固定攻擊與攻擊百分比是兩種屬性，不互相排除。有效初始詞條最多取四種，只要仍有有效候選，就加上五次全部命中有效詞條的強化機會。沒有有效候選則上限為0。

例如千夏有效屬性為固定攻擊、攻擊百分比。2號驅動盤主詞條為固定攻擊，副詞條只剩攻擊百分比可有效，故上限是初始1次加強化5次，共6。目前該盤有效3次，顯示3／6，整套顯示17／39。

| 位置 | 顯示 |
| --- | --- |
| 角色列表兩個數值 | 命座或影畫，以及目前／理論上限換算的整數百分比 |
| 角色詳情立繪第三個數值 | 全套目前／理論上限 |
| 聖遺物或驅動盤詳情標頭 | 單件目前／理論上限 |
| 副詞條各列 | 保留原本有效標記與 +N |
| 排序面板 | 目前有效次數、最大次數與達成率可各自排序 |

目前資料中的原神五星聖遺物、絕區零S級驅動盤皆可有四個初始副詞條與五次強化機會，因此理論上限不依目前裝備實際三或四詞條起手、現有等級或 +N 推算。兩遊戲仍分別驗證稀有度與合法屬性，再交共用公式處理。其他稀有度尚未定義時顯示未知。

列表不顯示等級。有效達成率以目前值除以上限、乘100後四捨五入到整數，個位數不補零，例如5%。已確認0次可顯示0%，任一值未知或分母無效則顯示 —。詳情維持角色等級、命座或影畫，以及目前／理論上限三項。裁切編輯器四頁也使用相同的列表與詳情規則。

上限明示依已確認有效屬性估算，未觀測到的屬性不補猜，也不回寫成無效標記。原神只採與觀測角色相符的有效註記，絕區零以名稱與單位識別屬性。未知集合、互相矛盾的有效標記、主詞條或稀有度不明時，上限顯示 —。目前與上限各自保留未知，全套加總仍須完整五件或六槽且不得重複。公式本身不改寫帳號現況，只有重新核對原始證據後才修正逐件資料。

本次補證確認阿羅夏杯暴傷列有效，整套22／42，列表52%。瑪薇卡目前羽毛由新裝備圖與重塑詳情確認五星、20級及有效標記，整套30／43，列表70%。沿用穩定物品ID與舊面板，不新增同件副本或重算舊指紋。查核範圍與依據見 [聖遺物補證](../../analysis/2026_11_13_artifact_recheck.json)。

## 音擎與證據

逐角色回看同一份原始影片，音擎記錄名稱、稀有度、目前等級、當時突破上限、精煉及兩項面板。畫面顯示 0 級就保存 0。名稱可與官方繁中條目核對字形，帳號數值仍以影片為準。

手機音擎詳情固定兩欄，依序為等級、精煉、基礎攻擊力及進階屬性，形成 2×2。稀有度與名稱在圖片旁，不占第五格。未知值保留位置與 —，避免格子跳動。

新證據使用獨立來源 ID，保留舊影片、截圖與匯入。這次另補正 11 號技能頁漏記，五項技能各為 1，核心技為 0。珂蕾妲未拍到音擎詳情，僅保存可確認的 A 級與 60／60，其餘未知。

## 導航材質

依使用者最新決定，兩款遊戲的列表與詳情頁首恢復不透明深灰單色，與整站背景一致。不使用模糊或漸層，維持無邊框、陰影與圓角。兩遊戲的搜尋、篩選、排序交由同一個完整列表頁首元件排列，避免頁面自行決定順序。

頁首在桌面與手機都向下捲動時隱藏，向上或回頂時顯示，鍵盤焦點在內時保持可操作。減少動態效果只取消動畫，不取消隱藏行為。底部導航與FAB保留既有材質及G／Z直接切換，內容卡維持深灰實體表面。

## 審閱與驗證

網站來源庫與GitHub帳號庫分開。審閱階段兩款遊戲曾以已登入伺服器提供唯讀部署快照，保存基準commit與帳號SHA，畫面不顯示審閱版標記。

依本次game stop指示，收尾版本移除部署快照覆寫與生成工具，正式API直接讀取GitHub main。帳號、來源索引及私人證據都按同一revision驗證。測試資料由明確指定的正式來源產生，僅供測試，不作為線上讀取失敗的替代。私人影片與新增證據不放進公開素材。

驗證包含資料 schema、證據 SHA、來源與舊證據不被覆寫、兩遊戲規則測試、介面型別、網站建置，以及桌面與手機的音擎 2×2、四槽隊伍、培養頁、列表百分比、排序篩選、未知值、焦點與返回位置。部署成功與線上驗收分開記錄。
